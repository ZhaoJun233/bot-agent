### 4.4 隔离环境回滚演练

在临时数据目录（`BOTAGENT_DATA_DIR` 指向独立路径，端口与令牌全部为合成值）跑通五步，用于验证回滚预案本身可执行：

| 步骤 | 动作 | 结果 |
| --- | --- | --- |
| D1 | 新数据目录启动宿主 | `/healthz` **200**；`/readyz` **503**（尚未连上协议端，符合语义）；`/status` 返回 `{"error":"unauthorized","mustChangePassword":false}`（未带令牌）。运行后产出 `botagent.db`(4096 B) + `botagent.db-shm`(32 768 B) + `botagent.db-wal`(646 872 B) + `plugins/` + `zba-event-sequence.boot` |
| D2 | `VACUUM INTO` 在线快照 | 成功；源库 `PRAGMA user_version`=**10**，表 **30** 张（其中业务表 **29** 张 + 1 张 sqlite 内部表）；快照库同为 10 / 30；快照文件 274 432 B |
| D3 | 把库的 `user_version` 改成 11 后重启 | 宿主**拒绝启动**（`/healthz` 不可达），日志首行 `Unhandled exception. System.InvalidOperationException: database_schema_newer` |
| D4 | 用 D2 的快照覆盖数据库后重启 | `/healthz` **200**；`user_version` 回到 10，表数 30 —— 快照可用于回滚 |
| D5 | 检查数据库文件权限 | `644`。**证明 `AppDatabase` 自身不做 chmod**，权限收紧只发生在 `SecretsStore` 的路径上（见 #121 的运维基线） |

结论：**"升级前 VACUUM INTO 快照 + 可打开校验"是可执行的回滚手段**；schema 只前向迁移，回滚只能靠快照，不能靠 down 迁移。

## 6. 已知偏差与未覆盖项

诚实记录本次基线**没有**证明的东西：

1. **CI 未在本轮运行**：以上全部是本机结果。GitHub Actions 的 `verify` / `web` / `e2e`（四矩阵）/ `integration`（三矩阵）需以实际运行为准。
2. **e2e 只跑了 chromium**：firefox / webkit / chromium-rate-limit 未在本机执行。
3. **容器化路径未验证**：采集机 Docker 守护进程未运行，镜像构建、容器内跑 harness（Linux 下 S21 的 `600` 权限断言）均未复现。
4. **本机无 8.x SDK**：构建实际由 SDK 10.0.101 完成，与 CI 的 `8.0.x` 不同。
5. **`EngineProbe` 不在 CI 中**：本机能跑通（20/0），但它没有进入 `ci.yml`，属于覆盖面缺口（#123）。
6. **真模型未评测**：`PipelineEval` 是确定性管线回归，不评价模型输出质量；「模型配置」类 bug（#103）不能靠它兜底。
7. **`PipelineEval` 的产物路径已失效**：它仍打印 `docs/engineering/eval-results/{results.json,results.csv,summary.md}`，而 `docs/engineering/` 已被提交 `04cb018` 整体删除 —— 属 #124 的死链修复范围。
8. **发布链路未在本轮执行**：公开快照由仓库外的发布脚本（快照 + 双重脱敏审计）生成，本次只读代码未实跑。

## 8. 复现方式

在仓库根目录，用**隔离环境**（清空 `BOTAGENT_*`、`QQCHAT_*`、`OPENAI_*`、`MINIMAX_*`、`TTS_*`、`HARNESS_*`、`HEALTH_PORT`）：

```sh
# 1) 构建（先宿主、后 harness）
dotnet build src/BotAgent.Headless/BotAgent.Headless.csproj -c Release
dotnet build tests/BotAgent.IntegrationHarness/BotAgent.IntegrationHarness.csproj -c Release

# 2) 单个探针（逐个跑全部 22 个）
dotnet run --project tests/BotAgent.ArchitectureProbe/BotAgent.ArchitectureProbe.csproj -c Release

# 3) 集成场景全量
dotnet tests/BotAgent.IntegrationHarness/bin/Release/net8.0/BotAgent.IntegrationHarness.dll

# 4) 前端
cd src/web && npm run typecheck && npm run test:unit && npm run build
npx playwright test --project=chromium

# 5) 隔离回滚演练：见 operations/rollback-playbook.md
```

```sh
# 6) 在线快照（先停写或至少确认无写入）
sqlite3 data/botagent.db "VACUUM INTO 'backup/qqchat_$(date +%Y%m%d_%H%M%S).db';"
```

> 探针一律用**合成临时目录**，不得指向生产 `data/`；集成场景自己造根目录，不要再给它传父级数据根别名覆盖。
> 日志里如果出现中文，先过 `tools/mask-cjk.py` 再贴出去。
