# 配置 UI 归属

Web 控制台按领域将配置入口拆分到对应一级导航，不再将模型引擎、平台驱动、系统核心包与对话插件混在同一视图中：

| 一级入口 / 分区 | 配置范围 |
| --- | --- |
| 系统配置 → 基础行为与人设 | 9 项核心通用参数：AI 对话总开关、机器人人设、群聊与私聊插话/续话节奏、并发回复上限、上下文条数和会话保留条数 |
| 系统配置 → 对话编排 | 主动回复、参与节奏、分句、消息过滤、审批等未归属插件的行为设置 |
| 系统配置 → 内置 Agent 与工具 | Agent 执行与服务器参数、工具范围、Agent 密钥 |
| 系统配置 → 健康日报 | 报告开关、发送时间和接收范围 |
| 系统配置 → 高级与系统包 | 9 个 `system.*` 核心引擎包的只读版本与运行状态总览，支持一键跳转至所属领域页 |
| 模型供应商 | 登记的模型供应商管理、默认主/快模型路由与采样参数、主模型 API Key 与独立供应商凭据、连通性测试及 `system.model-services` 路由引擎状态 |
| 消息平台 | QQ 私域、QQ 官方、飞书、本地调试驱动的连接启停、接入凭据、访问策略（含飞书秘密槽位）与消息能力声明 |
| 插件中心 → 对应插件卡片 | 8 个内置对话功能插件（音乐、语音含 TTS 密钥、表情包、戳一戳、氛围、画像、搜索、Token 配额）与第三方扩展；支持卡片直达沙箱界面（如表情包、Token 配额）以及插件市场与仓库导入 |

字段归属集中在前端的 `configuration-ownership` 与 `domain-catalog` 模块，以 UI 语义划分，保持原 `cfg-0.3.3` 字段、分区、数据库和 API 不变。基础项使用显式白名单，其余行为字段默认进入对话编排。插件声明的分区和字段优先归插件；配置定义按当前注册表查询，支持模块加载后的扩展登记、撤销与重新登记。

能力设置复用同一个配置事务编辑器，保留管理员权限、只提交改动字段、起草时的版本、冲突比较、服务端校验、生效状态及原键核对。秘密只显示元数据，替换输入为密码框；不新增官方 QQ Secret 写入口。

未保存草稿关闭时需要明确选择继续编辑或放弃；配置事务编辑器还支持明确保存后离开。提交中和未知结果不能通过关闭来丢弃原操作关联。切换视图时保留普通草稿和未确认操作，正常秘密输入会清除，隐藏的编辑器禁止普通编辑与保存。退出管理员前仍通过可见的离开确认处理草稿，保存前检查管理员权限与契约兼容性。安全锁定立即清除令牌、草稿和秘密输入，不等待保存确认，也不会自动提交。

未决操作的最小核对关联由按原服务和身份隔离的内存登记处保留：只包含操作键、目标、状态，以及额度来源/目标值或插件动作/版本等非秘密信息，不包含令牌、秘密、请求正文或结果。登记在请求发出前完成，组件卸载后的迟到响应仍更新原记录；同一目标未确认前禁止换键重复提交。重连相同身份后可以用原键只读核对，目标从能力目录消失时仍有统一核对入口。普通读取不冒充原操作回执；无法比较的秘密变更需要重新输入或明确确认。页面整体刷新不保留该内存登记处。能力草稿计数显示在能力导航上。

迁移仅调整前端入口，不自动保存、重启、提交、推送或部署。数组和对象字段沿用既有编辑器的可见/只读支持范围，不引入任意 JSON 写入。
