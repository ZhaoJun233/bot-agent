# 配置 UI 归属

基础配置只保留 AI 对话总开关、机器人人设、群聊与私聊冷却、并发回复上限、上下文条数和会话保留条数。

其余设置在「能力管理」中维护：

| 入口 | 配置范围 |
| --- | --- |
| 对话与参与策略 | 主动回复、参与节奏、分句、消息过滤、审批等未归属插件的行为设置 |
| 模型服务 | 主模型连接、模型选择、采样参数、主模型 API Key 和登记的模型供应商名称 |
| Agent 与工具 | Agent 执行与服务器参数、工具范围、Agent 密钥 |
| 平台接入与访问策略 | 私域、官方、飞书接入与访问策略，飞书秘密槽位 |
| 健康报告 | 报告开关、发送时间和接收范围 |
| 对应插件卡片的设置 | 音乐、语音、表情包、戳一戳、氛围、画像、搜索；TTS 密钥随语音设置 |
| Token 配额插件 | 每日额度、用量与持久启停，沿用专属配额 UI |

字段归属集中在前端的 configuration-ownership 模块，以 UI 语义划分，保持原 cfg-0.3.3 字段、分区、数据库和 API 不变。基础项使用显式白名单，其余行为字段默认进入对话能力。插件声明的分区和字段优先归插件；配置定义按当前注册表查询，支持模块加载后的扩展登记、撤销与重新登记。

能力设置复用同一个配置事务编辑器，保留管理员权限、只提交改动字段、起草时的版本、冲突比较、服务端校验、生效状态及原键核对。秘密只显示元数据，替换输入为密码框；不新增官方 QQ Secret 写入口。

未保存草稿关闭时需要选择保存、继续编辑或放弃；提交中和未知结果不能关闭丢弃。切换视图时保留普通草稿和未确认操作，正常秘密输入会清除，隐藏的编辑器禁止普通编辑与保存。锁定或退出管理员时，只有用户在可见的离开确认框中明确选择保存，才允许提交保留的草稿；提交前仍检查管理员权限与契约兼容性。能力草稿计数显示在能力导航上。会话失效时卸载并清理内存状态。

迁移仅调整前端入口，不自动保存、重启、提交、推送或部署。数组和对象字段沿用既有编辑器的可见/只读支持范围，不引入任意 JSON 写入。
