# 运行日志查看器

## 入口与用途

面板侧栏「运行日志」提供只读的近期运行事件视图，用于排查启动、连接和模型判定等问题。
本页不是聊天记录查看器，也不提供原始日志下载或展开原文。

- 实时接口：`GET /zba/v1/logs/feed`，沿用 ZBA read 鉴权。现有 `GET /zba/v1/logs?limit=200` 最新在前的快照契约继续兼容。
- 首次读取最近 200 条安全摘要，旧在上、新在下；以后每秒顺序读取游标后的增量。每批最多 200 条，有后续批次时立即补取，同时最多一个请求。正常网络、前台可见时以新日志 2 秒内显示为目标。
- 级别、来源及关键词只筛选已读取的安全记录，不执行磁盘全文搜索，也不根据自由文本推断等级。
- 默认跟随最新记录；向上滚动或选择文字时停止自动滚动，但继续接收。新增数量与“回到最新”帮助恢复跟随。长行只在日志区域内横向查看。
- “清空显示”只清除本地视图，保留接收游标及清空水位，不删除服务器记录；复制仅限选中文字或当前视口内的安全摘要，不导出全部缓存历史。
- 切换页面、浏览器隐藏时停止请求；恢复前台后按游标补取。锁定、身份变化、卸载时取消请求及定时器，迟到响应不能回填。
- 网络失败保留安全记录并标注过期，按 1/2/4/8/15 秒上限退避重连；401/403 清空受保护记录并停止重试。“暂无日志”不代表连接失败。

## 隐私边界

日志正文在**服务端**完成安全投影，浏览器从不接收原始自由文本。
来源采用固定组件白名单，消息仅按行首的宿主模板或独立原因码分类；不能因为聊天正文包含错误码就标成运行告警。未识别内容只显示隐藏占位及长度。
内存条目同时保留来源标记：当前进程完整写入的行才允许分类；磁盘回填行（包括看似完整的时间戳行）统一显示 runtime / 信息 / 隐藏占位，避免聊天换行伪造系统事件。
中文、英文、多行文本同样受此约束，不能通过日志输出路径、URL、凭据、成员或聊天正文。
所有响应使用 no-store。旧版原始日志接口不是这个页面的数据源。

页面仅以普通文本插值渲染摘要，不解析 HTML；没有「显示原文」开关。
前端类型校验检查时间、级别、字段类型、长度和容量，不把异常响应当成空日志。
真正的内容保密边界在服务端投影，而不是前端关键词过滤。

## 保留范围

增量读取请求只访问进程内最多 600 条的安全摘要缓冲，不触发额外的磁盘扫描或数据库读取。
现有宿主启动流程会从日志尾部回填最多 300 条，同时以 `canClassify: false` 加入增量缓冲；这些磁盘文本仅投影为“已隐藏”占位与字符数，不根据文本前缀推断可信等级或来源。旧快照接口继续保留原有行为；窗口外记录及原文不可通过日志页恢复。
这里的警告/错误数量仅对应浏览器当前保留的摘要窗口，并不是全天总数。
需要精确诊断时仍应遵守仓库的日志脱敏纪律，而不是放开原文访问。

## 增量契约

保留旧快照接口 `GET /zba/v1/logs?limit=200`（最新在前）；终端使用独立的 `GET /zba/v1/logs/feed`，不复用原始 `/api/events`，也不占用 ZBA 状态事件缓冲。每次请求均校验 ZBA Read 令牌，响应禁止缓存。

- 首次无游标读取：在同一锁内取得最近最多 200 条安全摘要及游标，按旧到新返回。后续只发送不透明 `cursor`；不接受 `limit` 等其他参数。
- 记录序号在日志写入锁内分配，同一进程中严格递增；进程标识与序号组成稳定 ID，不使用时间戳或正文去重。同毫秒、同摘要仍是不同记录。
- 单批最多 200 条，游标只推进到已交付记录；`hasMore` 为真时继续拉取，否则约 1 秒后再取，始终最多一个在途请求。
- 格式错误或显式空游标返回 400。过期、进程重启、游标超前分别给出 `expired` / `restart` / `ahead`，重置为最近窗口。只有过期重置提供可准确计算的 `omittedCount`，包括缓冲外及重置时跳过的记录；其他情况不猜测遗漏数。
- 前端清屏保留读取游标及清屏水位，不删除服务端记录。跨进程不能比较旧水位时，跳过重置历史并明确提示，避免已清屏历史重新出现。
