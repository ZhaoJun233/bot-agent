# Agent-06：ZBA、宿主集成与后端验收（Why / What / How）

> 修订：2026-10-07，第二版；前期参与契约设计，Wave 5 负责最终集成验收。
> 状态、共享写权及证据见[执行总纲](00-orchestration-and-dependency-graph.md)。
> 后端验收不等于发布授权；本轮仅修订文档。

## 一、为什么（Why）

解除前端静态资源内嵌，同时保留可以独立使用的后端。只做 CLI 和删除 wwwroot 不能交付新面板所需能力，必须把 Z-bot Backend API（ZBA）作为后端验收的一部分。

## 二、做成什么样（What）

### 2.1 交付边界

- Headless 负责组装、启动、健康、只读 CLI 和停机，不以“少于 300 行”代替职责验收。
- 拟建 Panel 工程承载 ZBA HTTP 适配层，由 Headless 同进程运行；依赖 Core 应用端口，不直接访问数据库。名称在落地前可经 00 记录调整，所有文档同步。
- API、健康、配置及任务管理不依赖 Web 静态资源；前端产物独立构建和部署。
- ZBA 首版能力及安全要求以[面板规划](../z-bot-panel-v0.1-beta-plan.md)为准，不在本手册维护第二份范围。
- CLI 默认只输出安全状态、计数、错误码；TTY 可刷新，非 TTY 输出可采集的低频状态行，不打印秘密、完整端点、群聊正文或原始报文。

### 2.2 ZBA 契约交付

在 Web 开工前交付实际 OpenAPI、合成请求与契约测试，而不是只有 C# 接口：

1. 路由、DTO、状态码和错误结构；稳定标识、分页/大小边界、未知字段策略及兼容版本。
2. 认证与授权方案、调用者隔离；Cookie 场景的 CSRF，跨域与事件认证的明确策略。
3. 配置版本、整批保存、秘密写入边界、幂等及已提交/已应用/需重启的区分。
4. 任务、审批、取消及事件恢复：断线不触发工具重做；查询能恢复最终状态。
5. 状态与错误只返回允许的元数据，不以“调试用途”暴露隐藏推理或原始工具载荷。

OpenAPI 的存放路径与生成/校验命令在实际工程建立后登记；当前不编造路由、端口或命令。

### 2.3 静态资源与配置过渡

- 先把现有 WebUiServer 中 API、健康和静态文件职责分清，建立等价契约测试，再解除资源内嵌。
- 只移除 Web 静态资源的构建耦合，不误删桥脚本等其它 EmbeddedResource。
- 没有验收通过的配置通路时保留既有可用管理能力；通过 ZBA 客户端或已验收导入流程承接后，再执行旧页面切换。
- CLI 不接受配置操作。任意 JSON 文件编辑不会自动覆盖当前数据库；需要文件导入时由 01 定义统一保存流程。
- 修改外部配置是否需要重启由字段规则决定；不把重启与重新编译混为一谈。

## 三、如何实施（How）

1. 前期与 01–05 共同确认应用端口和面板必选能力，登记接口缺口及消费者。
2. 各波次提供接入补丁，00 分批合入宿主并验证真实调用链；Wave 5 汇总完成剩余接入。
3. 实现 ZBA 与只读 CLI，完成认证、保存、任务及恢复的合成契约测试。
4. 在替代通路验收后移出静态资源、调整代理和发布产物；服务回环绑定与访问安全保持不退化。
5. 扩展架构护栏覆盖所有新工程及真实项目引用；预期存在的模块未找到或扫描为空时失败，不能把假空集算通过。旧扫描路径改变时迁移等价断言，不通过删除测试降低覆盖。
6. 执行总纲基线、当前完整回归和 ZBA 专项；记录排除项与测试迁移映射。
7. 本地生成产物并验证兼容、启动、停机和回退；生产操作另行申请，不为文档或本地验收连接线上数据。

写权：Panel 和独立 CLI 文件先登记；Host、项目引用、设置、架构护栏、CI、代理与部署配置均为共享文件，06 提供方案/补丁，00 最终合入。只有总纲记录临时移交后，06 才能独占写这些共享文件。

## 四、资源与回退验收

测量计划先由负责人确认：代表性合成负载、并发、预热与持续采样时长、空闲/峰值、托管堆/WorkingSet/容器/整机口径、GC、同机服务和 Swap 状态。与基线比较并确定预算，不把旧版 45–65 MB、95 MB、120 MB 当作已经证明或自动适用的门槛。

部署仍使用低内存环境适用的预构建产物路线，不在生产容器里编译。记录后端版本、配置/数据库版本、旧产物和回退条件；数据库迁移不可逆时先完成专门恢复方案。依总纲只回退本次产物/改动，不覆盖已有工作区。

## 五、后端 → Web 开工门禁

- [ ] Wave 1–4 已有当前准出证据，真实宿主路径运行。
- [ ] 安全、架构及适用全矩阵回归通过；排除场景如实披露。
- [ ] 面板规划中所有必选 ZBA 能力通过实际契约测试。
- [ ] 保存事务、版本冲突、秘密、审批/取消、重启与事件恢复均有负例。
- [ ] 后端脱离静态页面仍可运行和管理；旧测试职责迁移未丢失。
- [ ] 本地资源测量及产物回退演练达到已确认预算；生产验证未做时明确说明。
- [ ] 06 提交证据，00 核对，负责人明确批准 Web 开工。

任何一项缺失都不能用“CLI 已完成”解锁 Wave 6。正式使用还需要 Web/Beta 验收和独立发布批准。
