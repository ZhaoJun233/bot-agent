## 4. 稳定版本剩余步骤

1. 同步本次发布说明及进度资料，经既有脱敏流程更新 dev，再通过 dev → main PR 汇入；固定最终公开提交、文件树及对应 9 项 CI。
2. 为最终公开提交创建 v1.4.0 tag，核对 tag CI，按公开 tag 重新构建 Linux x86_64 后端与独立 Web 产物。
3. 记录版本、来源与哈希，完成最终产物的隔离 Linux 检查，发布 Release 并下载核对哈希。
4. 刷新部署条件，留存应用、数据库与前端回退点；部署后核对健康、版本、资源及关键路径，记录实际采用结果。
5. 实际使用观察、完整市场范围和 TypeScript 7 迁移继续单列；观察需维护者另行恢复后才能继续。
